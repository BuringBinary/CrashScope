# C-1：左侧全局记录控制区返工

日期：2026-09-21
范围：批次 C 的修订；只调整左侧状态区的产品布局与展示逻辑，不扩展到 D–E。

## 产品决策

左侧底部区域不再是重复品牌和一行“录制器状态”文字，而定义为跨页面持续存在的**全局记录控制区**。它在任何页面回答：当前是否记录、当前数据是否可信、现在可以执行什么操作。

首页保留详细状态简报；侧栏只保留紧凑摘要和一个主操作，避免把首页大卡片复制到每个页面。

## 实施内容

- 新增 `src/CrashScope.Desktop/SidebarRecorderPresentation.cs`，把 B 批次的 `LiveDataState` 映射为侧栏状态、可信提示和主操作：开始、停止、重试或忙碌。
- 左侧卡片现在显示：记录状态、文本状态点、数据可信提示、必要时的错误摘要，以及全局开始/停止/重试按钮。
- 状态矩阵覆盖：未录制、正在启动、等待首个采样、正在记录、采样过期、正在停止、采集故障。
- 正在记录且采样新鲜时显示最近采样时间；采样时间不确定时使用已有的“时间不确定”语义，不伪造实时性。
- 开始/停止操作复用现有 `AppService.SetRecordingAsync` 和 `RecorderOperationGate`，没有新增采集器、改变采样周期或改写诊断算法。
- 左侧状态区订阅录制状态和采样更新；关闭主窗口时退订。错误显示简短原因并保留完整错误 Tooltip。
- 删除底部重复的“Windows 飞行记录器”说明；设置仍固定在侧栏底部。
- 中英文新增侧栏状态、提示和按钮文案；状态理解不依赖颜色，颜色只作为辅助层。
