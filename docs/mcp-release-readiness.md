# 当前能力与打包就绪度

日期：2026-09-17

## 定位

当前是可进入目标机试用的 Windows 故障取证原型，不是已经证明能准确判定根因或自动修复故障的正式产品。

已有实现包括硬件/进程/前台活动与部分 GPU、显示、电源、内存、存储数据采集，ETW 事件采集，异常会话后的证据包与时间线，WPF 查看界面、Agent RPC 和启发式分析。实际采集覆盖受权限、硬件及驱动影响；采集项齐全不等于所有信号已在目标机验证。

本轮可靠性改进与验证见 `docs/mcp-reliability-convergence.md`：单写者、恢复队列、独立 session、明确故障状态、安全停止及清理保护。176 项选定回归通过，不代表全量测试或硬件长期验收完成。

## 打包判断

- **开发测试包：现在可以进入打包流程。** 先补齐发布脚本、执行 Release self-contained 发布并验收产物；目前尚未生成包含本轮修复的新包。
- **目标机试用包：完成隔离数据根短时实录、退出/再启动、证据查看与依赖验证后提供。** 推荐以被动采集为默认，不以未收敛的系统操作功能为主卖点。
- **正式安装发布：还需长时间实录、恢复场景、升级/卸载、权限与分发验证，并完成会误导判断的分析与操作边界修复。** 不给未经验证的日期承诺。

核对 `scripts/publish.ps1`：当前只发布 Agent 到 `dist/win-x64`，不含 Desktop/Service 的发布编排，也没有打包验收。它未显式检查 dotnet 退出码即打印成功提示，需在正式使用前补上失败退出。

推荐第一份产物为 Windows x64 自包含 ZIP，包含 Desktop 与 Agent 的独立输出目录、启动入口、版本/使用说明；默认 Agent 使用 --no-actions。不先要求 MSI、单文件或换技术栈。Desktop 暂仍有本地录制入口，需要在使用说明明确由谁拥有录制，不能同时录制同一数据根。

## 发布门槛建议

1. 停止旧版宿主并备份数据；旧版不遵守新锁协议。
2. Release 发布所有实际交付项目，确认资源、托盘、传感器和本机权限下的降级行为。
3. 对发布后的 EXE 而非仅 dotnet test 做启动、实录、停止、重启、RPC 和证据查看验收。
4. 目标机完成短时交互验证，再观察 24–72 小时常驻资源开销、数据增长、睡眠/唤醒和采样健康。该时长只是建议的试用窗口，不构成可靠性证明。
5. 后续按用户确认执行受控异常退出验证；不擅自断电、强杀已有程序或改系统设置。

DWM 合成开关不证明硬件/软件渲染模式，显存固定阈值和驱动关联统计仍存在已知局限，系统动作的审计/回滚与 RPC 并发/断线仍待加固。详见 `docs/mcp-current-implementation-review.md`；试用版需明确限制，不宣称准确诊断或自动修复。
