## 4. 实测问题及建议

以下问题均未修改源码或修复验证，严重程度为本次验收的初步分级。

### A01 中：最小窗口优先级“应用”按钮裁切

- 环境：中文、浅色，窗口 900×600，Agent 操作页，Agent 未连接。
- 现象：“进程优先级”一行最右侧应用按钮只剩一小段，文字不可见。不能将该页最小窗口布局判为通过。
- 复现：启动包 → 高级/Agent → Agent 操作 → 将窗口缩小至 900×600。
- 证据：`AgentActions-900.png`、`AgentActions-900-tree.json`。
- 对应源码：`src/CrashScope.Desktop/Pages/AgentActionsPage.xaml:115-129`。固定横排宽度至少为 120 + 6 + 130 + 6 + 64 = 326，超过窄窗口卡片可用宽度。
- 建议：自适应 Grid / 换行或窄窗单列布局；修复后同时检查电源计划、原因输入框、应用/回滚操作在中文与英文下的可达性。未点击被裁切按钮，未修改进程优先级。

### A02 低：Agent 连接错误提示被截断

- 1200×750 下 Agent 页面已有长路径错误提示越过可视边界；900×600 下 AgentActions 明显只显示 `No endpoint file at C...` 的前部。
- 证据：`AgentMonitor.png`、`AgentIncidents.png`、`AgentActions.png`、`AgentActions-900.png`。
- 建议：本地化短状态 + 可展开/可复制的详细错误，设置换行或省略与 Tooltip，避免让底层完整路径挤占操作区。未验证 Tooltip 是否存在，因此不声称详细信息完全不可获取。

### A03 低：中文界面仍有面向用户的英文残留

- Dashboard 的 CPU/GPU 显示 `unavailable / not recording`，健康说明仍为英文；RawSensorWindow 默认筛选项为 `All`。
- 证据：`Dashboard.png`、`RawSensors.png` 及对应 UIA 树。
- 硬件型号、驱动、原始事件字段等技术数据不一概认定为应翻译；本条针对停止/不可用提示与筛选项等 UI 文案。
- 旧 AgentActions 英文豁免不再适用：本轮该页主要标签确已是中文，但不能据此宣称全产品本地化完成。

### A04 低：悬浮条关闭图标显示为小方框

- 证据：`FloatingBar.png`，按钮位置可见方框状字符，而非清晰关闭图标。
- 对应源码：`src/CrashScope.Desktop/FloatingBarWindow.xaml:21-23`，内容为私用区字符 `E8BB`，该按钮没有显式图标字体。字体来源是待确认根因，不把推测当成已定位修复。
- 建议使用明确的图标字体或矢量关闭图标并补无障碍名称；还应验证真实点击关闭。固定深色背景属于已有产品决策，不是缺陷。

### A05 低：包 README 的构建来源描述与元数据矛盾

见基线部分。应修改打包文案来源，在下一次新包中生效，不回写本次已哈希的包。

补充观察：LiveMonitor 未录制/无事件时主体为空，只有侧栏提供录制状态。可考虑空态说明，但本轮没有足够证据将其定为功能故障。
