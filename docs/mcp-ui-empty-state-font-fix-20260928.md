## 原因

1. 仪表盘传感器数值和实时监控事件依赖录制器。上一轮明确限定未录制，因此没有新采样；但页面没有充分解释停止、等待和筛选为空的差别。
2. 首页打开数据目录、两处清除按钮没有使用已有 `IconTextTemplate`。私用区图标和中文被交给同一文字字体渲染，出现方框。
3. 健康趋势、悬浮条关闭按钮直接使用私用区字符，却没有相应图标字体。
4. 仪表盘型号缺省文字、曲线轴标题和健康趋势直接写英文；健康区域直接呈现分析层英文摘要，未明确区分历史分析与当前硬件状态。

## 修改

### 监控空态

- 新增 `src/CrashScope.Desktop/MonitoringPresentation.cs`，仅做状态到资源键的映射，不启动任何采集器。
- `ILiveMonitorEventSource` 增加只读 `DisplayRecorderState` 与 `StatusChanged`，复用 AppService 已有实现，不修改录制器生命周期。
- 实时监控增加常驻状态说明及空列表提示，区分停止、启动、停止中、故障、等待事件、筛选无结果。
- 状态变化和筛选立即刷新；已有事件在停止后保留，但明确标注为历史列表。
- 状态订阅与已有六类事件订阅一起释放，保留离页后的排队回调防护。
- 空态文本使用动态资源，因此无需实例化 AppService 就能检查中英文渲染。
- 仪表盘增加采样状态，区分未录制、等待首个采样、已收到但无可用值、采样中与故障。说明曲线只覆盖本页打开期间收到的数据；停止时不将残留数值作为新实时读数显示。

### 图标与按钮尺寸

- 首页数据目录、实时监控清除、仪表盘转换记录清除按钮补上图标/文字分离模板。
- 健康趋势改用普通 Unicode 箭头；无历史数据或未知趋势使用破折号，不伪装成持平。
- 悬浮条关闭按钮改用普通 `×`，添加本地化 Tooltip 与自动化名称，保留固定深色设计。
- 截图复核发现清除按钮原固定宽度不足，扩至 92；补充实际文字边界检查。实时事件类别列亦扩至 92。

### 中文及历史数据语义

- 型号缺省信息、CPU/GPU/内存曲线标题、时间轴与频率/功耗轴改用中英文资源。
- `Stable` 显示为“持平”，标签明确为“历史评分趋势”，并非“系统健康”。
- 健康说明改为本地化的历史事件数量和使用边界，不再直接把分析层英文摘要铺在卡片中。
- 本次只调整展示；历史评分算法、事件数据与原分析报告不变。此卡片不再展示原英文摘要中的驱动关联等细项，不应把新短说明视为完整分析报告。
