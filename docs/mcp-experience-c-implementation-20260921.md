# 批次 C：首页与导航减负

日期：2026-09-21
范围：`docs/mcp-product-experience-plan-20260921.md` 批次 C；不扩展到 D–E。

## 实施内容

### 导航分组

- 新增 `src/CrashScope.Desktop/NavigationLayout.cs`，集中保存稳定路由 ID、分组和固定属性，避免布局调整时依赖列表下标或重复猜测。
- 工作区保留“首页、录制器”；实时监控保留“仪表盘、实时监控”；故障诊断保留“事件、时间线”；硬件、磁盘健康、网速测试归入“工具”。现有页面和路由没有删除或改 ID。
- Agent 监控、Agent 事件、Agent 操作移入“高级 / Agent”折叠组。默认折叠，视觉上降低低频入口干扰；打开 Agent 路由时自动展开，用户手动展开/收起状态在本次主窗口生命周期内保留。
- 设置从可滚动路由列表移到侧栏底部固定区，在最小窗口下仍可直接到达。所有导航 RadioButton 共享 `MainNavigation` 组，保持键盘单选和当前路由互斥。
- 新增专用折叠组样式、展开箭头、悬停和键盘焦点反馈；没有使用发光或装饰性动效。

### 首页紧凑化

- 将“最后采样状态/时间”并入录制状态卡，与采集器健康摘要同一上下文展示，减少单独的“实时指标”重复标题；没有隐藏采集故障、缺失指标或过期状态。
- 收紧标题、状态卡、指标卡、事件列表和下方操作的间距与内边距，保留三项指标、真实破折号和事件直达入口。指标数值、采样新鲜度与 B 批次的可信状态逻辑未改变。
- 事件区域保留查看全部、重新读取、持久读取警告、明细展开和单条直达；仅做布局密度调整，不改事件读取契约、评分或导出安全边界。
- 中英文导航组标题同步更新：工具不再包含设置，高级组明确标为 Agent。

## 建议用户验收

1. 在方便切换版本时，先退出旧版并备份数据；启动 0.9.8，确认设置在侧栏底部且不随中间路由滚动消失。
2. 在默认和最小窗口用鼠标及 Tab/方向键展开“高级 / Agent”，进入 Agent 页面后确认分组自动展开，返回普通页面后偏好不被意外清空。
3. 在中英文、深浅主题下观察首页，确认未录制仍显示真实破折号，最近事件入口、重新读取和 B 批次警告仍可用。
4. 如需实测启停，请先在无风险环境操作；记录开始/停止反馈、实际 DPI、焦点可见性及任何布局遮挡，不强制终止正在持久化的宿主。
